# 📖 Stories

Short, true, public-safe tellings from real gardens — the moment a seed bloomed, the day someone was truly seen, the thing a garden learned that argument alone couldn't teach. Stories are how the commons stays measured at the floor instead of the ceiling: not *how many gardens*, but *what happened to someone*.

**The rules for this shelf are strictest:** no personal information beyond what the teller has already chosen to make public, no diagnoses, no family details, no identifying detail about anyone who didn't ask to be named. When in doubt, leave it out — a story with a hole in it is better than a person exposed by it.

*One starter seed lives here so the shelf doesn't open empty. The room that's left is for you.*
